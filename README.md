# Retool self-hosted blueprints

This is a collection of Terraform modules and usage examples to be used for deploying and managing a self-hosted Retool deployment in your own cloud provider.

## Requirements

- [Terraform](https://developer.hashicorp.com/terraform/install)
- [Helm v3+](https://helm.sh/docs/intro/install)
- [`kubectl`](https://kubernetes.io/docs/tasks/tools/)
- Admin credentials to your cloud of choice
